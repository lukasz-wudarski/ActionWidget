# ActionWidget Privacy Policy

Last updated: October 1, 2026

ActionWidget doesn't collect, store or share any personal data.

**What the app stores.** The widgets and buttons you set up, including the addresses, headers, user names and passwords you enter, are stored only on your device, so the widgets can use them. They are included in your device's own backups, like other app data.

**Requests.** When you tap a button, your device sends the request you set up directly to the address you entered. ActionWidget has no servers of its own, and no request or response passes through the developer. What the receiving server does with a request is up to that server and its owner.

**No tracking.** ActionWidget contains no analytics, advertising or tracking, and no third-party code that collects data.

**Local network.** The app asks for access to your local network only so that buttons can reach devices on it.
